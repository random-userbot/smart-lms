# Quick Reference: New Teaching Analytics Page

## 🎯 Accessing Teaching Analytics

### For Teachers:
```
Login → Teacher Panel → Click "📊 Teaching Analytics"
```

### For Admins:
```
Login → Admin Panel → Click "📊 Teaching Analytics"
```

---

## 📑 Four Main Tabs

### Tab 1: 📡 Live Tracking
**Purpose**: Monitor student activities in real-time

**What You'll See**:
- Course selection cards (click to select a course)
- Student activity metrics (active today, total activities, engagement rate)
- Live activity feed with timestamps
- Download CSV button for reports

**How to Use**:
1. Click on a course card to view its activities
2. See real-time feed of student actions
3. Monitor engagement metrics
4. Export data as CSV for external analysis

---

### Tab 2: 🎯 Teaching Score
**Purpose**: View ML-based teaching effectiveness indicators

**What You'll See**:
- Overall teaching effectiveness gauge (0-100)
- Component breakdown (engagement, content quality, etc.)
- Key insights and recommendations
- AI chatbot for score explanations

**How to Use**:
1. View your overall score and trend
2. Check component breakdown to identify strengths/weaknesses
3. Read AI-generated insights
4. Ask the AI chatbot specific questions about your score

**Example Questions for AI**:
- "Why is my student engagement score lower than content quality?"
- "How can I improve my teaching effectiveness score?"
- "What factors contributed most to my current score?"

---

### Tab 3: 📊 Engagement Analytics
**Purpose**: Analyze student engagement levels across courses

**What You'll See**:
- Course selection cards
- Student engagement scores (0-100)
- Engagement level distribution chart
- Student details table
- Download CSV option

**How to Use**:
1. Select a course using the card interface
2. View average engagement and distribution
3. Identify students needing attention (low engagement)
4. Download detailed report for follow-up

**Engagement Levels**:
- **80-100**: High Engagement ✅
- **50-79**: Moderate Engagement ⚠️
- **0-49**: Low Engagement (Needs Attention) ❌

---

### Tab 4: 👨‍🏫 Teacher Evaluation
**Purpose**: View student feedback and ratings

**What You'll See**:
- Overall rating (out of 5.0)
- Performance radar chart (6 categories)
- Sentiment distribution (positive/neutral/negative)
- Recent feedback comments
- Recommendation rate

**How to Use**:
1. (Admin only) Select a teacher using card interface
2. View performance summary metrics
3. Analyze radar chart for category strengths/weaknesses
4. Read recent student feedback
5. Monitor sentiment trends

**Performance Categories**:
- Overall
- Content Quality
- Clarity
- Pace
- Engagement
- Visual Aids

## 🎨 Card-Based Interface

### Course Cards
Beautiful gradient cards display:
- 📚 Course name and description
- 👥 Number of enrolled students
- 👨‍🏫 Teacher name
- 🆔 Course ID
- **Button**: "📊 View Analytics"

**Colors**: Cards automatically get different gradient colors for visual variety

### Teacher Cards (Admin View)
Compact cards for teacher selection:
- 👨‍🏫 Teacher name
- 🆔 Teacher ID
- **Button**: "View Score" or "View Evaluation"

## 📥 Export Features

### Available Downloads:
1. **Live Tracking**: Activity Report CSV
   - Timestamp, Student Name, Action Type, Details
   
2. **Engagement Analytics**: Engagement Report CSV
   - Student, Score, Level, Actions, Confidence

### How to Download:
1. Navigate to the relevant tab
2. Select a course (if required)
3. Click the "📥 Download..." button
4. CSV file downloads automatically

## ❓ Common Questions

### Q: Where did "Analytics", "Tracking", and "Teaching Score" pages go?
**A**: They're now unified in "Teaching Analytics" with separate tabs for each feature.

### Q: How do I view a specific course's analytics?
**A**: Go to Teaching Analytics → Choose the relevant tab → Click on the course card

### Q: Can I still download CSV reports?
**A**: Yes! Download buttons are available in Live Tracking and Engagement Analytics tabs.

### Q: What happened to "My Evaluation" page?
**A**: It's now Tab 4 (Teacher Evaluation) in Teaching Analytics.

### Q: Why am I not seeing data in Live Tracking?
**A**: Make sure students are enrolled in your courses and have been active. The page now displays real-time data properly.
